# Amazon Sumerian Host Babylon.js Demos

This repository contains updated versions of the official Amazon Sumerian Hosts Babylon.JS demos found in the [Amazon Sumerian Hosts GitHub repository](https://github.com/aws-samples/amazon-sumerian-hosts). These demos use the browser's speechSynthesis API instead of AWS Text-to-Speech (TTS), so they're easier to run locally and to deploy to your own web server. This makes them a great starting point for your own custom Sumerian Host applications.

![Amazon Sumerian Host characters](./docs/images/hosts_cover.jpg)

## Run local

In a terminal on your local machine, navigate to the repository root directory and run...

```bash
npm install
```

```bash
npm start
```
